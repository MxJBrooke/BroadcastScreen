OCR J836 Reference Desk

Format Check

Definition: Confirms that data fits a strict, predefined layout configuration template. The layout must match clear sequences of characters, numerical values, or symbol configurations in exact positions (e.g., Postcodes or structured ID codes).

Presence Check

Definition: Verifies that critical fields or data blocks have not been completely omitted. The computer program scans the form input and flags instances where required data entries remain completely empty or blank.

Range Check

Definition: Forces numerical values to fit within a predefined boundary window locked by an upper and lower mathematical threshold. Data falling outside those exact bounds is automatically flagged as an entry error.

Length Check

Definition: Monitors the data string array constraints. This rule checks if the total quantity of characters typed matches a specific fixed value, or complies with a predefined minimum or maximum length threshold.

Lookup Check

Definition: Compares and restricts input options directly against an index table or a pre-approved list of options stored inside the database. This stops users from generating unstructured free-text responses.
