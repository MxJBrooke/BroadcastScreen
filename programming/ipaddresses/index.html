Programming Constructs

In the OCR GCSE specification, you need to use these core programming constructs and data structures to build efficient programs.

1. Sequence

Code is executed line-by-line, from top to bottom. Every instruction runs in the exact order it is written.

# Example: Executing one step after another
print("Welcome!")
name = input("Enter your name: ")
print("Hello", name)

String Concatenation: Joining strings together using the + operator. Note that you cannot directly concatenate string datatypes with integers unless you cast them first!

# Example: Concatenating strings together
start = "192"
end = "168"
full_string = start + "." + end
print(full_string) # Outputs: 192.168

# Crucial GCSE Rule: You must convert numbers to strings to mix them
age = 16
message = "I am " + str(age) + " years old."
print(message)

2. Selection

Making decisions in code. The program takes different paths based on whether a condition is True or False.

# Example: Checking a condition
age = int(input("Enter your age: "))

if age >= 18:
    print("You are an adult.")
elif age == 17:
    print("Almost an adult!")
else:
    print("You are a child.")

3. Iteration

Repeating blocks of code (looping). There are two types: Count-controlled (FOR loops) and Condition-controlled (WHILE loops).

# Count-controlled (FOR loop)
for i in range(3):
    print("Loop number", i)

# Condition-controlled (WHILE loop)
keep_going = True
while keep_going == True:
    ans = input("Stop? (y/n): ")
    if ans == "y":
        keep_going = False

4. Functions & Subprograms

Subprograms are blocks of code assigned to a re-usable identifier. Functions return values back to the main program using the return keyword.

# Example: Defining and calling a Function
def format_ip(b1, b2, b3, b4):
    full_ip = str(b1) + "." + str(b2) + "." + str(b3) + "." + str(b4)
    return full_ip

# Calling the function and saving its result
my_address = format_ip(192, 168, 0, 1)
print(my_address)

5. 2D Arrays (Matrices)

A list of lists. Data inside a 2D array is structured into rows and columns, indexed using two sets of square brackets: array[row][column].

# Example: Working with 2D Arrays
records = [
    ["Alice", "Admin"],
    ["Bob", "User"]
]

# Accessing elements
print(records[0][0]) # Outputs: Alice

# Appending a new row item to the 2D array
records.append(["Charlie", "Guest"])

GCSE Core Knowledge: IP Addresses

An IP (Internet Protocol) Address is a unique identifier allocated to every device connected to a network, allowing them to communicate with one another.

  • IPv4 Structure: Composed of 4 numeric blocks (called octets) split cleanly by periods (e.g., 192.168.1.45).
  • Value Range: Each individual block is an 8-bit number, meaning values must strictly fall between 0 and 255.
  • DNS Links: Because numerical IPs are difficult for humans to remember, the Domain Name System (DNS) maps human-friendly URLs (like www.mxbrooke.co.uk) directly to these numeric IP addresses.
